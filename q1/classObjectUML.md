# SG4 - Understanding Classes and Objects
## P-pop
## My class presents all the properties and methods that P-pop music has.
## Properties
| Property | Data Type | Description |
|---|---|---|
| Name | string | The name of the song |
| Author | string | The name of the artist/band |
| Duration | integer | How long the music lasts |
| Release Date | string | The date when the music was released  |
## Methods
| Method | Description |
|---|---|
| play() | Starts the music |
| pause() | Stops the music |
| fast_forward(seconds) | Skips ahead in time |

## Design Explanation
### 1. Why did you choose this class?
- I chose this class because I am very fond of P-pop music and Im also proud of the creativity of our fellow Filipinos.
### 2. Which property is the most important? Why?
- The most important property is the name, because it is the face of the music and the most reconizable part.
### 3. Which method is the most useful? Why?
- Play is the most important method, because the music won't start without it.

### No major changes were needed from my original design.

|---|---|---|---|

| Author | string | Public | The author of the song is public, because it is another way to find the song. |
