## Answer the following questions:
### a. What is duck typing, as explained in the video?
- Duck typing is another way to achieve polymorphism besides Inheritance. As long as an object meets the minimum requirement of an attribute or method and resembles another, it could also be treated of that type. 
### b. What did the Car class need to have so it could work inside the same loop as Dog and Cat, even if it does not inherit from the Animal class?
- The car need the same attribute and or method as the dog and cat, so they can be treated the same way. 
## How does the code in 2.2 demonstrate polymorphism?
- It demonstrates polymorphisn because the different classes have the same method but performs differently. This shows that one function can treat different objects in different ways.
